# The "hey pantry" wake word

openWakeWord ships models for a handful of phrases ("hey jarvis", "alexa"...),
not "hey pantry", so this one is trained here from synthetic speech.

## How it was made

`~/Desktop/Development/wakeword/train_hey_pantry.sh` on the MacBook, run inside
an OrbStack Ubuntu 22.04 machine (the training recipe pins Linux-only,
Python 3.10-era packages):

1. Thousands of "hey pantry" clips are generated by a multi-speaker TTS model
   (piper-sample-generator, LibriTTS-R voices), plus near-misses that should
   *not* trigger it: "hey party", "hey patty", "hey panther", "pantry" alone...
2. Clips are mixed with room reverb (MIT impulse responses) and background
   noise and music (AudioSet, FMA) so they sound like a real room.
3. A small classifier is trained on openWakeWord's speech embeddings against
   ~2,000 hours of ordinary speech that must never trigger it.
4. The result is `models/wake/hey_pantry.onnx`, a few hundred KB.

To retrain: `orb -m wakeword bash -lc "cd ~/Desktop/Development/wakeword && ./train_hey_pantry.sh"`.

## Tuning

`PANTRY_WAKE_THRESHOLD` in `.env` (default 0.5). Raise it if it fires on TV
or conversation; lower it if you have to repeat yourself. Watch the score in
the service log while you say it: `journalctl -u pantry-voice -f`.

Delete or rename the model file to fall back to "hey jarvis".
